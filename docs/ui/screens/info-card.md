# Screen: info-card

> **Summary:** a sign/plaque card (building name + opening hours) shown when pressing Space at a building's sign bubble.

## Recognise
Overlay with a building name + hours, e.g. "Fairhaven Town Hall / Mon–Fri 9–17 (EN wording ❓)" (Town Hall, Mon–Fri 9–17).

## Actions
Read it (hours are useful); it's not an NPC.

## Exit
Esc.
