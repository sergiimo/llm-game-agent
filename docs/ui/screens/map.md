# Screen: map

> **Summary:** Illustrated island map with the quest route.

## Recognise
Mode `overlay`; full-screen painted island in a paper frame; little or no OCR text.

## Elements
- Pink pin = Tara. Dotted line = route to the current quest target. Unvisited areas covered by clouds.

## Actions
- `./wf key m`. Use `./wf look` to read the route.

## Exit
Esc.
