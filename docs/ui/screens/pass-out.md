# Screen: pass-out

> **Summary:** End-of-day screen when Tara stays up too late (~02:00) or runs out of energy.

## Recognise
Mode `overlay`; OCR "Time's up!" + "You're exhausted…" + a single button (EN wording ❓: was "Хр-р-р", maybe "Zzz").

## Elements
- Single button; the scene behind is dark (night).

## Actions
- Clicking the single button ends the day (next morning). It is the only option, but still ask the user first unless playing autonomously.

## Exit
Click the single button.
