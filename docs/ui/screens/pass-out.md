# Screen: pass-out

> **Summary:** End-of-day screen when Tara stays up too late (~02:00) or runs out of energy.

## Recognise
Mode `overlay`; OCR "Время вышло!" + "Ты выбилась из сил…" + button **Хр-р-р**.

## Elements
- Single button; the scene behind is dark (night).

## Actions
- Clicking **Хр-р-р** ends the day (next morning). It is the only option, but still ask the user first unless playing autonomously.

## Exit
Click Хр-р-р.
