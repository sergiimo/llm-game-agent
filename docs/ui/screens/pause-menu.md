# Screen: pause-menu

> **Summary:** Pause card with game-level options.

## Recognise
Mode `overlay`; OCR **Пауза**, "Игра сохраняется автоматически." (autosave).

## Elements
- Buttons: Продолжить игру (Continue), Настройки (Settings), Вернуться в меню (Back to menu), Выйти из игры (Quit).

## Actions
- Open/close with Esc. **Clicking "Продолжить игру" does not work** (L20). Never click Back-to-menu or Quit.

## Exit
Esc.
