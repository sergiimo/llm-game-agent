# Screen: pause-menu

> **Summary:** Pause card with game-level options.

## Recognise
Mode `overlay`; OCR **Game Paused**, "Game progress is saved automatically while you play." (autosave).

## Elements
- Buttons: Resume Game, Settings, Return to Menu, Exit Game.

## Actions
- Open/close with Esc. **Clicking "Resume Game" does not work** (L20). Never click Back-to-menu or Quit.

## Exit
Esc.
