# Screen: quest-popup

> **Summary:** Centered card announcing a quest or quest step.

## Recognise
Mode `popup`: OCR contains **Confirm**, or for completion **"Quest Complete!"** + button **Hooray!**.

## Elements
- Quest title, step text, optional progress counter (e.g. `0/2`), button **Confirm**.

## Actions
- Confirm: Space (or `./wf advance`). Read and record the step text first.

## Exit
Space.
