# Bouquet Table

[Workstation]
  itemName: Bouquet Table
  description: A workstation for creating flower arrangements.
  buildCost: 20x Wood; 5x Iron Ingot; 10x Glass; 600 coins
  size: 3x2
  unlockRequirements: If It's Bouquet With You Quest
  location: Tool Shed

All bouquets are crafted instantly. Sellable bouquets can be sold at Violet's Violets.

Craft any seasonal bouqet, then speak to a previously romanced character you want to rekindle with and use the heart icon to gift it to them; their relationship level will return to Intimate Friend. Once the relationship heart is filled again, you can then restart the dating process from the beginning.
