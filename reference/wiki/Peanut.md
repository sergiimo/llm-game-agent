# Peanut

[Forage]
  itemName: Peanut
  location: Forest
  season: Spring, Summer

## Description
A hearty-tasting nut that grows wild in the woods in Spring and Summer.  Use it in delicious recipes.

## Recipes
Peanut can be used in the following recipes: 

* Buddha's Delight
* Satay Noodles
* Peanut Brittle
* Pacoquinha (Peanut Rolls).
