# Sewing Machine

[Workstation]
  itemName: Sewing Machine
  description: Used to create outfits! Unlock new outfit designs by selling outfits to Violet Miranda at Violet's Boutique. Built in the tool shed.
  size: 1x2
  buildCost: 10x Iron Ingot; 20x Wood; 5x Silver Ingot; 600 coins
  location: Tool Shed

The Sewing Machine has four categories of outfits that can be made: Casual, Work, Formal, and Magic.; ;  -Casual, Work, & Formal Outfit designs are purchased in Violet's Boutique; new patterns are stocked as Tara sells outfits to Violet. ; -Magic Outfit designs are first unlocked after reading a letter from Violet after collecting magical animal produce for the first time.; ; 

Base Materials
| Item | Details |
| Cloth | can be crafted with a loom using cotton, wool, or alpaca wool. |
| Silk | can be crafted with a loom using silk thread. |
| Leather | can be crafted with a tanning station using tanning solution; plus (animal hide, fish, or mushroom/shiitake mushroom). |
| Silk Thread | can be crafted with a silkworm box using mulberry leaves; harvested from a mulberry tree. |
; ; 
Dye/Other; 
Dyes can be crafted with a mortar and pestle.; 
Dyed cloth/silk/leather/thread can be achieved via a dyeing bath using the corresponding dye.; 
Coatings can be crafted with a cauldron.; 
Magic Cloth can be crafted with a loom using corresponding magical animal wool.
; ; 
Tables show full materials listed together + sortable material breakdowns; 
Tip: For dye counts, use ctrl+f to search & you can record the total from there.
