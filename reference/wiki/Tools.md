|  |  | This pickaxe can break up small rocks and boulders, but it requires a lot of energy. Natalia can upgrade it in her blacksmith. |
|  | Gift from Bruno. | Bruno gifted you this fishing rod, which you can use to catch fish as long as you have enough bait. |
