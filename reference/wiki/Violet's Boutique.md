# Violet's Boutique

| <b>Violet's Boutique</b> |
| <b>Mon | Closed |
| <b>Tue-Sat | 9am-5pm |
| <b>Sun | Closed |

"Dress up any ocassion with our petals and patterns."; 

Violet's Boutique is the new name of Violet Miranda's shop after she begins selling sewing patterns for outfits. After an introductory quest, both Violet's old stock of flower seeds and new sewing patterns can be bought at the same location.

Buying sewing patterns allows the player to craft new outfits for Tara using a Sewing Machine. Selling crafted outfits back to Violet unlocks more patterns for sale.

The changing room in the back of the store can be used to change into a random outfit.
