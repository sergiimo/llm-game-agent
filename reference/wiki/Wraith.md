# Wraith

Wraiths are dangerous spirits born of the places where the Wellspring’s magic has been sucked dry. Some have been trapped inside the Gloaming for centuries. One of the responsibilities of the coven is to keep the Wellspring balanced so they do not escape.

Wraiths can possess humans to influence their behavior, but it is possible to exorcise them using an incantation made with Fennel Powder, an item the possessed person made, and an item that carries an important memory to the possessed person. 

The following quests involve exorcising wraiths:

* Wraithing in Anticipation
* Seton’s Secrets
* Forget Me Not
* Locket Up
