# Retro 2026-10-26 21:16 — potato quest session (planting + watering)

**Scope:** from "continue playing the potato quest" until the user's interrupt after `wf advance` overran.
**Outcome:** potato planted and watered (Крошка-картошка: planting and watering steps done). New quests received:
*Занимательная микология* (The Fungus Among Us: 2 mushrooms for Gramma) and *Скоростные знакомства* (The Most
Elaborate Icebreaker: meet the mayor at Town Hall). A clock appeared: *Понедельник 10:00* (Monday 10:00).

## How we did
About **35 tool calls** for what should take about 12.

### Where time went
1. **3 calls per step.** Every step was action → `wf look` (only writes a file) → `Read` the image. Roughly 60% of calls.
2. **Discovering the interact key: about 12 calls.** Tried E, Settings (3 tabs), Continue ×2 (clicking it doesn't work;
   Escape does), clicking the bubble. Then found **Space** = interact. A one-time cost, but only if written down.
3. **Fixed sleeps** (1.5–2.5 s) after every action instead of waiting for the screen to change.
4. **Trial-and-error positioning.** Walking to the bed overshot, so one extra look/correct round.
5. **`advance` overran (risky).** After the quest popups, a day/clock banner ("Понедельник 10:00") appeared.
   `state` called it `overlay`, so `advance` pressed Space 5 more times on a frame that wasn't changing. Space is also
   the interact key in gameplay, so need to verify that nothing was triggered.

## Suggestions (by payoff)
1. **One call per step:** `wf do <action> --look` acts, waits for the screen to change, then prints state text plus a
   small look path. Steps go from 3 calls to 2, or 1 when text suffices.
2. **Wait-for-change instead of sleeps:** poll for frame change (~0.3 s, cap ~3 s).
3. **Safer `advance`:** stop on the 2nd identical frame; treat the clock/day banner and gameplay as stop conditions; only
   press Space when a subtitle line ("Name: …"), a quest popup (Подтвердить) or a cutscene is showing; re-calibrate the HUD
   template since a clock now appears.
4. **Delegate loops to Haiku:** dialogue, walking routes, fishing as text-only loops in a Haiku subagent that reports a
   summary. Keep planning and visual positioning on the main model.
5. **Faster positioning:** detect the prompt bubble (cream round badge near Tara) by pixel check, then
   "walk until bubble" with no images.
6. **Record findings right away:** Space = interact/confirm, clicking Continue fails (use Esc), dialogue = subtitles,
   clock appears. Avoids repeating the 12-call discovery.

Expected: planting + watering about 10–12 calls instead of about 35.

### Extra changes found while applying
- **Warm daemon** (`tools/wfc.py` client + `wf.py serve`, auto-started; `./wf stop` to reload): avoids ~1 s imports
  and **~5 s Vision cold start per call**. `state` 5–15 s → **0.3 s** (game in background).
- **In-memory capture + half-res OCR**: screenshot 0.53 → 0.06 s; OCR 1.56 → 0.44 s and more accurate.
- **App Nap opt-out** in the daemon.

### Not solved / open (⏸)
- **With the game in front, calls are still slow**: `state` ≈3 s, `do` ≈5 s (vs 0.3 s with the game in background).
  Contention from the game, WindowServer and a running VM (`com.apple.Virtualization` at 85% CPU). Options needing a
  decision: run the game windowed / at lower resolution / with MSAA off (changes user settings, so ask first), or stop
  the VM.
- **Incident:** while benchmarking with the game unpaused, day 1 ran to 02:00 → pass-out popup (Хр-р-р). Now rule 0
  in AGENTS.md / wylde-play / game-onboarding: pause before non-game work. The popup was left open (time frozen) pending
  the user's go-ahead.
- Cause of the bed panel opening without Space (L25) is still unknown.
