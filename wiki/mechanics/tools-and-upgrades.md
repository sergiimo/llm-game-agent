# Tools And Upgrades

> **Summary:** Rusty watering can/axe/pickaxe → copper/silver/gold at the Blacksmith; rod from Bruno; shovel crafted.

## Rules (wiki)
| Upgrade | Cost |
|---|---|
| Iron Watering Can | 5 Iron Ingot + 3 Wood + 250c (4× capacity) |
| Copper Axe / Pickaxe | 3 Copper Ingot + 5 Wood + 250c each |
| Silver Axe / Pickaxe | 10 Silver Ingot + 5 Wood + 1000c each |
| Gold Axe / Pickaxe | 12 Gold Ingot + 10 Wood + 3000c each |
| Shovel | 20 Iron Ingot + 5 Wood + 150c |
Priority: pickaxe. Details: `reference/wiki/Tools.md`.
