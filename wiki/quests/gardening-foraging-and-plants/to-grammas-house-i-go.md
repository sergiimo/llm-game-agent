### Start state
- New game, Spring Y1 day 1. Tara stands just south-east of the **twin-statue fountain** in the Town Center square.
- Visible: Kai's striped stall (left, Kai standing beside it), Bruno's teal fish stall (right of statue),
  Cafe Moretti (teal building, right edge), Lina waving in the lower park.
- HUD: only 3 round buttons: **pause (Esc)** top-left, **map (M)** and **journal (J)** top-right. The map
  icon has an orange "!" badge. **No clock, energy or money HUD yet**, since the tutorial hides them.

### Steps
1. Focus and verify control: `./wf status` should show `accessibility: true` and `screen_recording: true`.
2. Read the quest: `./wf key j`. The journal **To-Do** (Quests) opens with one entry. The right page shows the
   description and a **Show Hint** (Show hint) button.
   - `./wf click-text "Show Hint"` shows a popup: "Check your map if you're not sure where to go." (where
     to go.) Then `./wf click-text OK --exact`, and `./wf key escape` closes the journal.
3. Optional: `./wf key m` shows an illustrated island map. A **pink pin** marks Tara (town square). A **dotted
   path** runs north from the square, then west along the upper road, then north-west to the farmhouse (top-left
   of the island). `./wf key escape` closes it.
4. Walk (camera follows Tara; W/A/S/D = screen up/left/down/right):
   ```
   ./wf path left:1.0 up:3.0      # toward the big staircase north of the statue
   ./wf path left:0.6 up:3.5      # step left off the lamp post, climb the stairs → landing below Town Hall
   ./wf path left:1.2 nw:1.5 up:0.6 left:3   # left flight of stairs → upper street by The Jewelry Box
   ./wf path left:4               # west along the road → Blacksmith (Natalia sweeping inside)
   ./wf path up:0.7 left:5        # dirt path west past the signpost (house-arrow ← = farm)
   ./wf path left:2 nw:2 left:2   # through the stone gate pillars → area transition
   ```
5. Area transition: the screen letterboxes and a location banner **"Hazel Wylde's Farm"** (Hazel Wylde's Farm)
   appears bottom-left over a waterfall/pond shot, followed by a slow camera pan over the farmhouse (well, 2 small
   garden beds, mailbox, tool shed on the right). Gramma (white hair, purple coat) stands at the well.

### Expect / gotchas
- **Key presses need ≥0.2 s hold** (Unity polls per frame). `wf key` defaults to 0.2 s; at 0.08 s, J was ignored.
- `wf` must bring the game to the front. Activation through `NSRunningApplication` is ignored on new macOS,
  so `wf` uses `open -b com.studiodrydock.mayflower`. The first screenshot after focusing can catch the
  full-screen Space sliding in (the image looks shifted). Wait about 1 s.
- The game owns **two** 1920×1080 windows; one is always black. `wf` auto-picks the rendering one (cached in
  `.shots/.window_id`; delete that file if screenshots turn black after a game restart).
- Tara snags on lamp posts and stair edges. If a `walk` does nothing, side-step 0.5 s and retry.
- Vision OCR ignores the tiny key badges (Esc/M/J). That's normal; game text in dialogs and journal OCRs fine.
- Cutscenes: letterbox bars (black rows at the top ~0–125 px and bottom ~950–1080 px) and no HUD. **Space advances
  to the next shot.** Don't spam it blindly: observe each shot, because dialogue choices may appear.

# To Gramma's House I Go

To Gramma's House I Go is the first quest you receive when you first arrive in Fairhaven. It is a tutorial quest that leads you to Gramma's house. Time is paused for the duration of this quest.

Hint
Check your map if you're unsure.
